# 孩子四岁多了咋还走不稳？洛阳医生问诊：这不是补钙的事儿...

> 更新时间：2026-09-16 (UTC+8)

咿呀学语、蹒跚学步是每个孩子的必经阶段。随着年龄的增长，孩子说话会越来越流畅，走路也越来越稳当，而有一些孩子，过了学步期仍然走不稳，一不留神就会摔跤，家长可不要以为是缺钙哦！

四岁多了仍走不稳，更不会蹦跳

说起多多（化名）的病情，他的爸爸连声叹气：“快两岁时，多多才学会走路，走起路来摇摇晃晃的，总摔跤。我当时觉得孩子小，磕磕碰碰很正常，以为再长大些就好了。”

多多过了3岁，跟他年纪相仿的小朋友都疯跑着玩了，他走路还是不稳当，平衡感很弱，身子总是往前倒。“我扶着他，一步一步教他走路，情况也没有改善。”

本文图片均来源于网络

“多多一直很瘦弱，稍微一动就大汗淋漓，每天起床要翻身俯卧才能爬起来，蹲下起身时得扶着东西支撑。”多多的爸爸说，“我们以为这是孩子缺钙造成的，专门给他买了儿童钙片，他吃了半年多也不见好转。”

多多4岁多了，连上楼梯都很费劲儿，更不用说蹦跳着玩耍了。无奈之下，多多的父母带着他四处求医。

进行性肌营养不良症却跟营养不良无关

在市妇女儿童医疗保健中心，儿童康复科主任刘文详细询问了多多的病情，经过查体，判断孩子得的是假肥大型进行性肌营养不良症。于是，她为多多做了抽血化验、肌电图检查以及基因检测，结果证实了她的判断。

多多的父亲很不解地说：“多多看起来瘦弱，但他的进食量不比别的孩子小，我们也很注意他的营养，为什么会得‘肌营养不良症’呢？”

刘文解释说，进行性肌营养不良症并不是营养不良造成的，而是一类由于基因缺陷导致的肌肉变性病，主要表现为进行性加重的肌肉无力和萎缩。多多所患的假肥大型进行性肌营养不良症是其中较常见的一种。

市妇女儿童医疗保健中心遗传室主任王亚男说，由于多多体内其中一种基因出现了缺失突变，体内不能产生抗肌萎缩蛋白，导致了肌肉逐渐萎缩、无力。

产前基因检测可预防，别盲目补钙

刘文介绍，假肥大型进行性肌营养不良症常见于男孩，女孩可能携带致病基因，但基本不会发病。

有些患儿会像多多这样发育迟缓，有些孩子则小时候发育正常，从4岁多开始出现走路摇摆、腰部前凸、小腿肚明显变粗等症状，7岁以后症状一年比一年严重，十几岁时可能丧失行走能力。

该病没有被治愈的可能，只能通过一些康复手段在短时间内增强患儿的肌肉力量和功能，延缓肌肉萎缩、肌无力和关节挛缩的发生。所以王亚男说，对于有遗传病家族史或生育过这类患儿的孕妇，产前基因检测是重要的预防措施。

家长要注意的是，在孩子的成长过程中，一旦发现其学会走路的时间比较晚，行走缓慢且容易摔跤，切不可认为是孩子腿软就盲目给孩子补钙，最好带孩子到综合性的大医院进行排查确诊。
